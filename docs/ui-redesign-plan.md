# UI 重构计划

## 目标

在不改变功能、快捷键、鼠标交互和黑白灰定位的前提下，重做 `src/ui.rs` 的视觉结构，解决当前界面暴露的问题：

- 顶部导航按固定宽度裁剪，中文标签实际显示不完整。
- 表格列被拉伸到全屏宽度，行选中反白过长，数字列左对齐。
- 概览页大面积留白，CPU 曲线在首次启动时只有一个柱，像渲染错误。
- 设置页内容稀疏，缺少有效分组。
- 弹窗没有边框、没有背景压暗，视觉层级不足。

## 技术选型

沿用现有依赖，不新增库：

- `ratatui 0.30`：`Block`、`BorderType::Rounded`、`Padding`、`Table`、`Line` 对齐、`Sparkline`。
- `unicode-width 0.2`：按终端显示宽度计算导航标签和操作按钮。
- 现有 `App` 状态与 `ClickAction`，不修改业务逻辑。

## 实现思路

1. 统一内容宽度（最多 112 列）并居中，顶部、页面、页脚对齐。
2. 顶部导航按实际字符宽度布局；窄终端切换为两字短标签；修复 `? 帮助` 点击区。
3. 页面标题改为编号 + 标题 + 副标题 + 右侧元信息，内容区使用细圆角面板分组。
4. 概览页：
   - 资源卡片显示标签、数值、进度条和明细，窄屏改为 2×2。
   - CPU 活动面板加入坐标轴、时间说明；数据不足显示“正在采集趋势”。
   - Sparkline 只取最近 N 个采样点，避免历史容量大于图表宽度后显示旧数据。
   - 系统信息独立面板；底部快捷入口使用键帽按钮。
5. 文件/进程页：
   - 表格放入圆角面板，列宽按内容约束，大小/CPU/内存/状态右对齐。
   - 修正表头行高导致的行点击命中偏移。
   - 选中行保持反白，但限制在面板内容宽度内。
   - 进程状态转换为中文。
   - 操作栏改为可点击键帽 + 标签，窄屏自动使用短标签。
6. 终端页保留最大 Shell 区域，只增加状态栏和分隔线。
7. 设置页改为“外观 / 运行时 / 关于”面板，窄高度时降级为单面板。
8. 弹窗统一为圆角边框、内边距、压暗背景；帮助内容提供完整版和紧凑版。
9. 页脚使用键帽提示，并保留 `Ctrl+Q 退出`。

## 依赖 API

- `ratatui::widgets::{Block, BorderType, Padding, Row, Table, Sparkline, Widget}`
- `ratatui::buffer::Buffer` 与 `Widget` trait：实现全屏压暗效果。
- `Line::alignment`：表格数字列右对齐。
- `unicode_width::UnicodeWidthStr::width`：中文标签宽度。

## 兼容范围

- 最小界面 64×18，继续提供原有“扩大终端”提示。
- 所有功能键、点击操作、帮助、弹窗、预览、终端透传保持不变。
- 保持 `F1–F5`、`Ctrl+Q`、鼠标捕获与恢复行为。

## 风险

- 面板边框和键帽会占用 1–2 行/列，需同步调整鼠标命中区域。
- 表格表头实际只占 1 行，原代码按 2 行计算行命中，需修正。
- 弹窗压暗通过 Buffer 遍历实现，只影响 RGB/索引色，不改变终端默认色。
- 窄屏下文字可能截断，采用短标签、隐藏次要元信息和紧凑布局规避。
